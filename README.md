# SMP TPI Gedangan Official Website

Repository ini digunakan untuk pengembangan website resmi SMP TPI Gedangan. Website ini bertujuan untuk memberikan informasi yang jelas dan mudah diakses mengenai sekolah, termasuk profil, kegiatan, dan berita terbaru.

## Alamat
Jln. R Kanjeng Jimat,  
Gedangan, Kec. Gedangan,  
Kab. Sidoarjo, Jawa Timur,  
Kode Pos: 61254.

## Deskripsi Proyek
Proyek ini merupakan bagian dari program **Kampus Mengajar Batch 8** yang bertujuan untuk meningkatkan aksesibilitas informasi pendidikan melalui penggunaan teknologi. Saya bertindak sebagai web developer untuk proyek ini, bekerja sama dengan pihak KM8 SMP TPI Gedangan untuk merealisasikan website ini.

## Fitur Utama
- Informasi tentang sekolah
- Kegiatan dan acara terkini
- Berita terbaru
- Galeri foto
- Kontak dan peta lokasi
